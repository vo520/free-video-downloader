# 宝塔面板部署指南

本文档介绍如何在宝塔面板中部署 AI 万能视频下载总结器。

---

## 一、环境准备

### 1.1 购买云服务器

推荐配置：
| 配置项 | 推荐 |
|--------|------|
| 系统 | Ubuntu 22.04 |
| CPU | 2 核 |
| 内存 | 4 GB |
| 带宽 | 5 Mbps |

### 1.2 安装宝塔面板

在服务器上执行以下命令安装宝塔：

```bash
# Ubuntu 安装命令
wget -O install.sh https://download.bt.cn/install/install-ubuntu_6.0.sh && bash install.sh
```

安装完成后：
- 记录登录地址（如 http://your-ip:8888）
- 记录用户名和密码

---

## 二、宝塔面板配置

### 2.1 登录宝塔面板

打开浏览器访问 http://your-ip:8888 ，输入用户名和密码登录。

### 2.2 安装必要软件

在「软件商店」中安装：

| 软件 | 用途 |
|------|------|
| Nginx | Web 服务器、反向代理 |
| Python | 后端运行环境 |
| PM2 Manager | Node.js 进程管理（可选） |

安装 Python：
1. 在软件商店搜索「Python」
2. 点击「安装」，选择 Python 3.11 版本

---

## 三、上传项目

### 3.1 创建网站

1. 进入宝塔面板 → 「网站」→「添加站点」
2. 填写：
   - 域名：your-domain.com（或暂时使用 IP）
   - 备注：AI 视频下载器
3. 点击「提交」

### 3.2 上传项目文件

1. 进入网站根目录：`/www/wwwroot/your-domain.com/`
2. 删除默认的 `index.html`
3. 上传项目文件：

方法 A：通过 Git 克隆
```bash
cd /www/wwwroot/your-domain.com/
git clone https://gitee.com/vo520/free-video-downloader.git .
```

方法 B：通过 SFTP 上传
- 使用 FileZilla 或其他 FTP 工具连接服务器
- 上传整个项目到根目录

---

## 四、配置后端

### 4.1 安装后端依赖

```bash
cd /www/wwwroot/your-domain.com/backend

# 创建虚拟环境（可选）
python3 -m venv venv
source venv/bin/activate

# 安装依赖
pip3 install -r requirements.txt
```

### 4.2 配置环境变量

```bash
cd /www/wwwroot/your-domain.com/backend
cp .env.example .env
nano .env
```

修改配置：
```env
DEEPSEEK_API_KEY=sk-your-api-key
JWT_SECRET=your-strong-secret-key
FRONTEND_URL=http://your-domain.com
```

### 4.3 测试后端

```bash
cd /www/wwwroot/your-domain.com/backend
python3 main.py
```

确认启动成功，不要关闭终端（后续会用 Systemd 管理）。

---

## 五、配置 Nginx 反向代理

### 5.1 进入网站设置

在宝塔面板中：网站 → 点击网站名称 → 「设置」→「反向代理」→「添加反向代理」

### 5.2 配置反向代理

| 配置项 | 值 |
|--------|-----|
| 代理名称 | api |
| 代理类型 | HTTP |
| 目标地址 | http://127.0.0.1:8000 |
| 发送域名 | $host |

### 5.3 配置静态文件

将前端文件放到正确位置：

1. 构建前端：
```bash
cd /www/wwwroot/your-domain.com/frontend
npm install
npm run build
```

2. 复制构建文件到网站根目录：
```bash
cp -r dist/* /www/wwwroot/your-domain.com/
```

## 六、使用 PM2 管理后端（推荐）

### 6.1 安装 PM2

在宝塔面板「软件商店」中安装「PM2 Manager」

### 6.2 添加后端项目

1. 打开 PM2 管理界面
2. 点击「添加项目」
3. 填写：
   - 项目名称：video-downloader
   - 项目路径：/www/wwwroot/your-domain.com/backend
   - 启动文件：main.py
   - 执行用户：root

### 6.3 启动项目

点击「添加」后，PM2 会自动启动后端服务。

## 七、域名解析

1. 在域名服务商处添加 DNS 记录：
   - 类型：A
   - 主机记录：@
   - 值：你的服务器 IP
2. 等待生效（几分钟到几小时）

## 九、常见问题

### Q1：后端无法启动？

检查：
```bash
# 查看 PM2 日志
pm2 logs

# 查看 Python 是否正确安装
python3 --version

# 检查依赖是否安装成功
cd /www/wwwroot/your-domain.com/backend
pip3 install -r requirements.txt
```

### Q2：API 返回 404？

检查 Nginx 反向代理配置是否正确，确保代理到 127.0.0.1:8000

### Q3：视频解析失败？

1. 确保 ffmpeg 已安装：`ffmpeg -version`
2. 检查服务器网络是否可以访问目标网站
3. 升级 yt-dlp：`pip3 install --upgrade yt-dlp`

### Q4：AI 总结不可用？

1. 检查 DeepSeek API Key 是否配置正确
2. 检查 API 余额

## 十、开启 HTTPS（推荐）

1. 在宝塔面板中：网站 → 点击网站名称 → 「设置」→「SSL」
2. 点击「Let's Encrypt」免费申请
3. 勾选「强制 HTTPS」
4. 点击「保存」

## 十一、后续维护

### 更新代码
```bash
cd /www/wwwroot/your-domain.com
git pull

# 重新安装依赖
cd backend && pip3 install -r requirements.txt

# 重新构建前端
cd ../frontend && npm install && npm run build
cp -r dist/* ../

# 重启后端（PM2）
pm2 restart video-downloader
```

### 查看日志
```bash
# PM2 日志
pm2 logs

# Nginx 日志
tail -f /var/log/nginx/access.log
tail -f /var/log/nginx/error.log
```
