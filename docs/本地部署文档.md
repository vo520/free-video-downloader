# 本地部署文档

## 一、项目概述

### 1.1 项目信息

- **项目名称**：AI 万能视频下载总结器（SaveAny）
- **项目类型**：前后端分离的全栈应用
- **技术栈**：Vue 3 + FastAPI + SQLite + yt-dlp + DeepSeek

### 1.2 核心功能

1. 多平台视频解析和下载（支持 B站、YouTube、抖音等 1800+ 平台）
2. AI 视频总结摘要
3. AI 生成思维导图
4. AI 视频问答
5. 字幕导出
6. 用户注册登录 + 会员权限
7. Stripe 国际支付

## 三、部署步骤

### 3.1 克隆项目

```bash
git clone https://github.com/liyupi/free-video-downloader.git
cd free-video-downloader
```

### 3.2 配置环境变量

```bash
cd backend
cp .env.example .env
```

编辑 `backend/.env` 文件，填入配置：

```env
# 必需配置
MINIMAX_API_KEY=sk-your-minimax-api-key
JWT_SECRET=my-local-dev-secret-123

# 可选配置（不填不影响核心功能）
STRIPE_SECRET_KEY=sk_test_xxx
STRIPE_WEBHOOK_SECRET=whsec_xxx
STRIPE_PRICE_ID_MONTHLY=price_xxx
FRONTEND_URL=http://localhost:5173
```

**配置说明**：
- `MINIMAX_API_KEY`：MiniMax 开放平台 API Key，用于 AI 视频总结功能
- `JWT_SECRET`：用户登录 Token 的签名密钥，本地开发可随意设置
- Stripe 相关配置：可选，不影响视频下载和 AI 总结核心功能

### 3.3 安装后端依赖

```bash
cd backend
pip3 install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 3.4 安装前端依赖

```bash
cd frontend
npm install
```

如需加速，可切换国内镜像：
```bash
npm config set registry https://registry.npmmirror.com
```

## 七、常见问题

### Q1：ffmpeg 未安装，下载视频画质低？

**解决**：
```bash
# macOS
brew install ffmpeg

# Ubuntu / Debian
sudo apt install ffmpeg
```

### Q2：端口被占用？

**解决**：
```bash
# 查看占用端口的进程
lsof -i :8000    # macOS / Linux

# 终止占用的进程
kill -9 <PID>
```

### Q3：pip install 安装依赖报错？

- bcrypt 编译失败：运行 `xcode-select --install`（macOS）
- Python 版本过低：需要 Python ≥ 3.10
- 网络超时：使用国内镜像 `-i https://pypi.tuna.tsinghua.edu.cn/simple`

### Q4：前端请求后端接口返回 CORS 错误？

确保通过 `http://localhost:5173` 访问前端页面，前端会自动将 `/api` 请求代理到后端。

### Q5：下载抖音视频失败？

1. 确保使用的是抖音分享链接（如 `https://v.douyin.com/xxx`）
2. 检查网络是否正常
3. 尝试升级 yt-dlp：`pip install --upgrade yt-dlp`
