# 线上部署指南

本文档介绍如何将 AI 万能视频下载总结器部署到国内云服务器（如阿里云、腾讯云）。

---

## 一、服务器准备

### 1.1 购买云服务器

推荐配置：
| 配置项 | 推荐 |
|--------|------|
| 系统 | Ubuntu 22.04 LTS |
| CPU | 2 核 |
| 内存 | 4 GB |
| 带宽 | 5 Mbps |
| 硬盘 | 40 GB |

推荐服务商：
- 阿里云：https://aliyun.com
- 腾讯云：https://cloud.tencent.com

### 1.2 安全组配置

开放端口：
| 端口 | 用途 |
|------|------|
| 22 | SSH 连接 |
| 80 | HTTP 网站访问 |
| 443 | HTTPS |
| 8000 | 后端 API（可选） |

## 二、连接服务器

```bash
ssh root@你的服务器IP
```

## 三、安装依赖

### 3.1 安装 Python 和相关工具

```bash
# 更新系统
apt update && apt upgrade -y

# 安装 Python 和 pip
apt install -y python3 python3-pip python3-venv

# 安装 ffmpeg
apt install -y ffmpeg

# 安装 Node.js
curl -fsSL https://deb.nodesource.com/setup_18.x | bash -
apt install -y nodejs

# 验证安装
python3 --version
node -v
npm -v
ffmpeg -version
```

### 3.2 安装项目依赖

```bash
# 创建项目目录
mkdir -p /var/www/free-video-downloader
cd /var/www/free-video-downloader

# 克隆项目（从 Gitee）
git clone https://gitee.com/vo520/free-video-downloader.git .

# 安装后端依赖
cd backend
pip3 install -r requirements.txt

# 安装前端依赖
cd ../frontend
npm install
```

## 四、配置环境变量

```bash
cd /var/www/free-video-downloader/backend
cp .env.example .env

# 编辑 .env 文件，填入你的配置
nano .env
```

配置内容：
```env
# DeepSeek API Key（用于 AI 视频总结）
DEEPSEEK_API_KEY=sk-your-api-key

# JWT 密钥（生产环境请使用强随机字符串）
JWT_SECRET=your-strong-random-secret-key

# Stripe 支付配置（可选）
STRIPE_SECRET_KEY=sk_test_xxx
STRIPE_WEBHOOK_SECRET=whsec_xxx
STRIPE_PRICE_ID_MONTHLY=price_xxx
FRONTEND_URL=https://your-domain.com
```

## 五、配置 Nginx

### 5.1 安装 Nginx

```bash
apt install -y nginx
```

### 5.2 配置 Nginx

```bash
nano /etc/nginx/sites-available/free-video-downloader
```

写入以下内容：

```nginx
# 前端静态文件
server {
    listen 80;
    server_name your-domain.com;  # 替换为你的域名

    root /var/www/free-video-downloader/frontend/dist;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    # API 代理到后端
    location /api/ {
        proxy_pass http://127.0.0.1:8000/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

### 5.3 启用配置

```bash
ln -s /etc/nginx/sites-available/free-video-downloader /etc/nginx/sites-enabled/
nginx -t
systemctl reload nginx
```

## 七、配置 Systemd 服务（后端）

```bash
nano /etc/systemd/system/video-downloader.service
```

写入以下内容：

```ini
[Unit]
Description=AI Video Downloader Backend
After=network.target

[Service]
User=root
WorkingDirectory=/var/www/free-video-downloader/backend
ExecStart=/usr/bin/python3 /var/www/free-video-downloader/backend/main.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

启动服务：

```bash
systemctl daemon-reload
systemctl start video-downloader
systemctl enable video-downloader
```

## 十、常见问题

### Q1：后端启动失败？

检查日志：
```bash
journalctl -u video-downloader -n 50
```

常见问题：
- 端口被占用：修改 main.py 中的端口
- 环境变量未配置：检查 .env 文件

### Q2：视频解析失败？

1. 确保 ffmpeg 已安装：`ffmpeg -version`
2. 检查网络是否可以访问目标网站
3. 查看 yt-dlp 版本是否最新：`pip3 install --upgrade yt-dlp`

### Q3：AI 总结功能不可用？

1. 检查 DeepSeek API Key 是否正确配置
2. 检查 API 余额是否充足
3. 查看后端日志中的错误信息

---

## 十一、域名解析

1. 在域名服务商处添加 A 记录：
   - 主机记录：@
   - 记录值：你的服务器 IP
2. 等待 DNS 生效（通常几分钟到几小时）
